# Exercício Prático: Sintetizador de Voz (Web Speech API)

Este repositório foi estruturado para o aprendizado prático da manipulação de APIs nativas do navegador através do JavaScript moderno (ES6). Ele está dividido em duas etapas para facilitar o fluxo de desenvolvimento do aluno.

## 📁 Estrutura do Repositório

O projeto contém duas pastas principais:

1. **`sintetizador-de-voz-limpo/`**: É o ponto de partida do aluno. Contém a estrutura HTML básica centralizada, estilos visuais iniciais e uma lógica JavaScript simples. Os alunos devem abrir esta pasta para realizar as atividades de programação.
2. **`sintetizador-de-voz-finalizado/`**: É o gabarito completo do professor. Contém todas as funcionalidades, controles dinâmicos de áudio, seleção de voz assíncrona e feedbacks visuais aplicados com sucesso. Deve ser usado apenas para consulta ou após a entrega do exercício.

---

## 🚀 Como Executar o Projeto Localmente

### 1. Clonar ou Baixar o Repositório
Abra o seu terminal e clone o projeto com o Git:
```bash
git clone https://github.com/leo-gomes-dev/Sintetizador-de-Voz.git
```
*Caso não utilize Git, clique no botão **Code > Download ZIP** no topo desta página e extraia a pasta em seu computador.*

### 2. Abrir no Editor de Código
1. Abra o seu editor (recomendado: **VS Code**).
2. Vá em `File > Open Folder...` e escolha a pasta raiz do projeto.
3. Para codificar os desafios, concentre suas alterações nos arquivos dentro da pasta `sintetizador-de-voz-limpo`.
